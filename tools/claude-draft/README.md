# وسيط «مساعد الصياغة» — إعدادٌ لمرّةٍ واحدة

مساعد الصياغة في «عين المشرف» يعمل بطريقين:

- **بلا إعداد (مجّانيّ):** «نسخ الطلب لـClaude» ← الصقه في Claude ← انسخ الردّ ← «الصق ردّ Claude» في العين.
- **ربطٌ مباشر:** زرٌّ واحد يصوغ ويعرض النتيجة. يحتاج هذا الوسيط، لأنّ مفتاح Claude لا يوضع في الموقع (ملفّاته عامّة).

## الخطوات (قرابة ١٥ دقيقة)

1. **مفتاح Claude:** ادخل `platform.claude.com`، واشحن رصيداً صغيراً، ثمّ API Keys ← Create Key، وانسخ المفتاح.
   تقريرٌ كامل بنموذج Sonnet يكلّف قرابة سنتين أمريكيّين.
2. **حساب Cloudflare مجّانيّ:** `dash.cloudflare.com` ← Workers & Pages ← Create ← Worker ← سمّه `svf-draft` ← Deploy.
3. **الشيفرة:** Edit code ← احذف ما فيه والصق محتوى `worker.js` كاملاً ← Deploy.
4. **المتغيّرات:** Settings ← Variables and Secrets ← أضف:
   - `ANTHROPIC_API_KEY` (Secret): المفتاح من الخطوة ١.
   - `SVF_KEY` (Secret): كلمةٌ طويلة تختارها أنت (٢٠ حرفاً فأكثر).
   ثمّ Deploy.
5. **في عين المشرف:** «الإعدادات» ← «مساعد الصياغة»: الصق رابط الوسيط (`https://svf-draft.<اسمك>.workers.dev`) والكلمة نفسها.

## مهمّتان

- **«draft»** (الافتراض): صياغة الإجادة والتطوير والتوصيات — حتّى ٢٤ ألف حرفٍ و٢٠٠٠ رمزٍ للردّ.
- **«guide»**: تحويل صفحات دليل المعلّم إلى بطاقة درس (`js/eye-guide-import.js`) — حتّى ٧٠ ألف حرفٍ و٨٠٠٠ رمز، **مرّةً لكلّ موضوع**
  (البطاقة تُحفظ ولا يُعاد تحويل النصّ نفسه). تكلفتها نحو عشرة سنتات للموضوع.

بعد أيّ تعديلٍ في `worker.js`: Edit code ← الصق الملفّ كاملاً ← Deploy (المتغيّرات تبقى كما هي).

## ما يحميه الوسيط

- **المفتاح** في Cloudflare وحدها، لا في الموقع ولا في المتصفّح.
- **الكلمة** (`SVF_KEY`): من لا يعرفها لا يستعمل الوسيط على حسابك. تُحفظ في متصفّحك وحده.
- **المصدر:** لا يقبل إلّا طلباتٍ من `supervisor-mct.com` (أو ما تضعه في `ALLOWED_ORIGINS`).
- **التكلفة:** النموذج وحدّ الطول يحدّدهما الوسيط، لا الموقع. ويمكنك وضع حدٍّ شهريٍّ للإنفاق في `platform.claude.com`.

## ما يُرسَل إلى Claude

الصفّ وعنوان الدرس وجنس المعلّم، ولكلّ بندٍ مستواه وجملة مستواه وعبارات الأدلّة. **لا يُرسَل** اسم المعلّم ولا المدرسة،
ولا كلام المعلّم بنصّه، ولا ملاحظاتك المكتوبة، ولا صورةٌ ولا صوت.
